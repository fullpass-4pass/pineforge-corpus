# PineForge Pendulum SAR Rotation

An independently authored PineForge parabolic-rotation strategy. It exercises
the supported `ta.sar` series in a conventional long-only market-entry and
market-close lifecycle with a deterministic time guard.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent result from the native PineForge
Corpus verifier; deterministic compilation alone is insufficient.
