# PineForge Spectrum Array Deque

An independently authored PineForge breadth strategy. It maintains a bounded
array of recent return signs, iterates over the deque, and admits a fixed-size
market entry only when the positive share and trend filter agree.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent result from the native PineForge
Corpus verifier; deterministic compilation alone is insufficient.
