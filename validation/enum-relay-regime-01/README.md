# PineForge Relay Enum Regime

An independently authored PineForge example where a declared enum and
`input.enum` choose between coherent trend and mean-reversion regimes. The
default trend path uses fixed-size market entry/close and an ATR stop.

This candidate is private and unqualified until its exact TradingView export
and native PineForge Corpus comparison both complete with an Excellent result.
