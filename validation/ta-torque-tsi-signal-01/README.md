# PineForge Torque TSI Signal

An independently authored PineForge smoothed-impulse strategy. It combines the
supported true strength index with Wilder-style signal smoothing and a broad
price regime, without inheriting the rejected runtime-risk interaction.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent result from the native PineForge
Corpus verifier; deterministic compilation alone is insufficient.
