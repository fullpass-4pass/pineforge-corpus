# PineForge Gyroscope CMO Median

An independently authored PineForge momentum strategy. It combines a rolling
median with the Chande Momentum Oscillator and keeps order behavior to
fixed-size market entry and close instructions.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent native PineForge Corpus result.
