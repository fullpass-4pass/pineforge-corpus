# PineForge Rangefinder Daily Reference

An independently authored PineForge daily-reference strategy. It requests the
prior daily high and low together with gaps-off, lookahead-off semantics and
uses those closed boundaries for entry and exit decisions.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export, byte-equivalent daily platform-bar reconciliation,
and an Excellent result from the native PineForge Corpus verifier;
deterministic compilation alone is insufficient.
