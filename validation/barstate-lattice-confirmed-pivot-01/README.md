# PineForge Lattice Confirmed Pivot

An independently authored PineForge strategy that admits EMA transitions only
when bar confirmation and RSI momentum agree. It exercises
`barstate.isconfirmed`, a user-editable boolean confirmation gate, fixed sizing,
market entry/close, a maximum holding boundary, and an ATR stop.

This candidate is private and unqualified until its exact TradingView export
and native PineForge Corpus comparison both complete with an Excellent result.
