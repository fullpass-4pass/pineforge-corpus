# PineForge Cadence Matrix Pairing

An independently authored PineForge multi-horizon confirmation strategy. It
transposes a two-by-three grid of price direction and volume firmness into
horizon-aligned pairs, then requires broad pair consensus.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent result from the native PineForge
Corpus verifier; deterministic compilation alone is insufficient.
