# PineForge Quarry ALMA Correlation

An independently authored PineForge trend strategy. It combines an Arnaud
Legoux moving average with a rolling price-volume correlation requirement and
uses fixed-size market entry and close instructions.

The Apache-2.0 source is PineForge-owned. Admission requires the exact private
TradingView trade export and an Excellent result from the native PineForge
Corpus verifier; deterministic compilation alone is insufficient.
